# vivid-nook-mini



处理日常小任务的工具

## 用法

```bash
cat data.txt | node index.js
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/vivid-nook-mini.git
cd vivid-nook-mini
npm install
```
